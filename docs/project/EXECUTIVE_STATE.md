# Executive State

## What This Is

AI Leverage Library is a Git-native, evidence-aware field manual for reproducible AI techniques. Canonical technique cards describe outcomes, inputs, workflows, verification, failure modes, and human authority; websites and tools are intended to remain adapters over that content core.

## North Star

A practitioner or AI agent should be able to find and apply an appropriate technique without hidden context, verify what happened, preserve authority boundaries, and retain evidence that shows whether the technique created a useful outcome. Repository correctness, user value, operational use, and commercial value remain separate proof levels.
